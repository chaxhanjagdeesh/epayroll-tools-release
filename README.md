## Installation

1. Download the latest installer from the Releases page.
2. Run `ePayroll-Tools-Setup-*.exe`.
3. Complete the installation.
4. Launch **ePayroll Tools**.
5. Enter your license key when prompted.

The application will automatically check for available updates on startup.

---

## Automatic Updates

ePayroll Tools uses GitHub Releases for application updates.

When a new version is published:

```text
New Release
     ↓
GitHub Release
     ↓
ePayroll Tools detects update
     ↓
Update is downloaded
     ↓
Application installs the new version
